COMANDOS GIT

git init . -> cria um repo git na pasta atual
git status -> mostra o status do trabalho (de cada arquivo)
git add nome_arquivo -> adiciona arquivo para ser commitado
git commit -m "frase" -> faz commit do que estava para ser commitado
git log -> mostra todos os commit e quem alterou (historico de todos os commit)
git add . -> pasta atual
git add * -> tudo
git diff <arquivo> -> mostra as alterações
git reset -> volta o status do arquivo
git checkout -b -> cria uma ramificação (uma copia da main, secundaria, etc...)
git branch -> mostra todas ramificaçõs
git checkout (branch) -> entra dentro dela
git merge (branch) -> trás da branch e leva pra que voce quer
